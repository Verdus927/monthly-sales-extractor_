# monthly-sales-extractor
# 월간 매출 보고서

자료 엑셀을 넣으면 월간 매출 보고서(대시보드·손익·비용 상세)가 자동으로 만들어지고 PDF로 저장할 수 있는 페이지.

👉 **[페이지 바로 열기](https://verdus927.github.io/monthly-sales-extractor_/)**

## 쓰는 법
1. 보고 월 고르기 (기본값: 지난달)
2. 자료 파일을 한 번에 끌어다 놓기 (종류는 칼럼을 보고 자동 인식)
3. 체크목록에서 빠진 자료·기간이 다른 자료 확인, 팩스는 직접 입력
4. **PDF로 저장** → 인쇄 창에서 "PDF로 저장", 배경 그래픽 켜기
5. **설정 파일 내려받기**로 이번 달 값이 반영된 설정 파일을 보관 (다음 달 전월 비교에 쓰임)

## 넣는 자료
| 자료 | 어디서 | 쓰이는 곳 |
|---|---|---|
| 위사 주문 (주문번호 기준 / 주문상품 기준) | 위사 관리자 | 총거래액, PG 수수료, 대분류·입점사 |
| 뿌리오 발송결과 | 뿌리오 → 충전 → 발송결과 | 홍보문자 회차·건수·비용 |
| 위사 메세지 월별통계 | 위사 관리자 | 위사 이용료(메시지 충전금) |
| 입점사 정산 | 정산 파일 (선정산 있으면 합쳐서 한 탭) | 입점사 수수료 수익 |
| 제일리본 발주서 | 발송 기준 주문 목록 | 자사상품 판매 |
| 환불 시트 | 환불 스프레드시트 내려받기 | 자사상품 환불 |
| 3PL 거래내역서 | 딜리브 (다음 달 도착) | 자사상품 물류비 |
| 설정 파일 | 이 페이지에서 내려받아 보관 | 단가·원가·위사 이용료·월별 이력 |

## 민감정보
- 파일은 브라우저 안에서만 읽고 어디에도 올라가지 않음
- 계좌번호·은행·수수료율·수령자 정보는 읽지 않고 보고서에도 넣지 않음
- 원가·이용료·월별 매출 이력은 이 저장소가 아니라 **설정 파일**에만 보관
