# 월 매출 통계 추출기

위사 주문 엑셀을 올리면 매출 통계를 자동으로 뽑아주는 도구.

## 쓰는 법
１. 위사 엑셀 업로드 (주문번호 기준 / 주문상품 기준, 한 파일 또는 두 파일)
２. 통계 확인 → 표 복사 또는 엑셀 다운로드

## 나오는 통계
- 사이트 총거래액 (주문번호 기준 실결제)
- 결제방법별 실결제액 + 수수료 추정
- 대분류별 / 입점사별 판매액·수량·비중
- 대분류별 세부 상품 TOP 5

## 핵심 규칙
- 금액 기준 = 주문번호 기준 실결제 (정산 탭과 일치)
- 예치금/할인은 비례배분으로 자동 차감됨
- 빈 입점사명 = 제일무역(자사)으로 처리
- 인터넷 연결 필요 (라이브러리 로드용)
